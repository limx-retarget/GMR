# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
privately rather than opening a public issue.

Use the **"Report a vulnerability"** button on the GitHub Security tab:

https://github.com/limx-retarget/GMR/security

We will respond and coordinate a fix before any public disclosure.

## Supported Versions

Only the latest commit on the default branch (`limx`) is actively maintained.
